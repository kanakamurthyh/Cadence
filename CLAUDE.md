# Cadence

- After every change to this project (code, data, results, docs), update `project context.md`:
  add a dated change-log entry, refresh the status, results and pending sections, and bump "Last updated".
- Thresholds are fitted on T1 only; never retune on T2/T3.
- Run long jobs (refs, ladders, evaluate) with `nohup` and at most 3 workers.
